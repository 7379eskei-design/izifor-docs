# IziFor Documentation

Public product and engineering documentation for **IziFor**, a peer-to-peer logistics marketplace connecting senders with people who are already traveling on a compatible route.

## Core product rule

IziFor is **not** a dedicated courier-driver dispatch service. Travelers are already making the trip and can carry compatible packages for senders.

## Documentation status

These documents describe the intended product and target backend architecture. Some flows are currently represented in the prototype and will become server-authoritative as Firebase/Google Cloud backend work is implemented.
